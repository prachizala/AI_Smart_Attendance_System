# Screenshot Placeholders & Capture Checklist

To make your GitHub repository stand out to recruiters, capture clear PNG screenshots (recommended resolution: 1280x720 or 1920x1080) and place them in this folder with the exact filenames below:

| Filename | Screen Description | How to Capture |
| :--- | :--- | :--- |
| `01_admin_dashboard.png` | Admin Dashboard overview showing total employees, attendance donuts, and analytics charts. | Open `http://localhost:5173` in your browser and screenshot the main overview tab. |
| `02_mobile_checkin.png` | Mobile Expo camera check-in screen with the face frame and GPS badge. | Screenshot the Expo app on your phone during the check-in camera view. |
| `03_geofence_map.png` | Geofence verification map showing the 100m green circle around campus. | Open the Geofence / Map view in the Admin Dashboard or Mobile app. |
| `04_leave_approval.png` | Leave Management table showing pending and approved employee leave requests. | Navigate to "Leaves" tab in the Admin Dashboard. |
| `05_payroll_payslip.png` | Itemized payslip calculation modal with deductions and net salary. | Navigate to "Payroll" tab and open a sample employee payslip. |
| `demo.gif` | 60–90 second screen recording of a full check-in flow (Mobile camera ➔ Admin Dashboard refresh). | Record using OBS / ScreenToGif and convert to an optimized GIF. |
